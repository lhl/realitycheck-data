# Why Are We Still Doing This?
Source: https://www.wheresyoured.at/why-are-we-still-doing-this/
Date: March 17, 2026

## Summary
AI boosters should no longer be allowed to use future tense when describing AI capabilities. The subscription model is fundamentally broken for AI companies with no clean path to profitability.

## Key Arguments

### Subscription Model Is Broken
- A $20/month Claude subscriber can burn up to $163 in compute
- Claude Max $100 and $200/month plans explicitly let users burn more tokens
- Users are not educated in or thinking about "token burn" — software has never made them do so before
- Switching to API pricing would be catastrophic for user retention
- AI companies have deliberately used subscriptions to make AI seem more affordable than it actually is

### Claude Code Economics
- For 100 engineers at $200/month = $240,000/year
- If switched to API at $10/day = $365,000/year
- At $25/day = $912,500
- At $40/day = over 10% of salary costs
- Anthropic's own docs say average Claude Code cost is $6/developer/day, with 90% of users below $12/day
- Reddit user reported $200-300/day in API costs; switched to Lambda GPU cluster running Qwen 3.5 for $40-50/day
- Another user's parallel Claude Code sessions on $200/month plan = ~$12,000/month in actual API costs
- One user who hit Max limits and needed "another hour or two" spent $600 in API costs

### Anthropic Financials
- Anthropic turned $30 billion (in funding) into $5 billion (in lifetime revenue)
- Gross margin estimated at 38% (per The Information)
- Training costs kept out of gross margins — Zitron calls this "inherently deceptive"
- Anthropic and OpenAI project 70% gross margins by 2027/2029 respectively, but this excludes training

### The Uber Comparison Is Invalid
- Uber does not own vehicles, does not pay for gas
- Uber charged per-ride (not subscription)
- Uber's PP&E has been $1.5-2.1B since founding
- Uber burned $30-40B total vs OpenAI raising $42B in one year

### Enterprise AI Revenue (Still Tiny)
- Adobe AI-first ~$60M/quarter
- ServiceNow $600M ACV (unclear meaning)
- Salesforce Agentforce $800M
- Shopify/Workday minimal
- None break out AI revenue clearly
- Cursor: $2B annualized on $3B raised in 2025

### Total AI Spending
- Anthropic and OpenAI raised $200B+ in funding
- ~$700B in hyperscaler capex in 2026 alone
- $800B+ already spent
- Tens of billions for CoreWeave
- $178.5B in data center debt deals in 2025
