## Stage 3: Dialectical Analysis

### Steelmanned Argument
Authoritarian consolidation can proceed via parallel moves across institutions and information environments, with corruption and coercion serving as coordination mechanisms. A synthesis that tracks multiple axes can reveal systemic patterns missed by single-event reporting.

### Strongest Counterarguments
1. **Overfitting/confirmation bias**: a checklist lens can interpret diverse events as one pattern even when causal links are weak.  
2. **Base-rate neglect**: many described features (nationalism, security rhetoric) exist in normal democracies too.  
3. **Evidence heterogeneity**: mixing partisan trackers, opinion pieces, and primary documents risks treating asserted claims as established facts.
